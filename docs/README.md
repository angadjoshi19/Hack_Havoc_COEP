# OceanEmbed: Satellite Embedding-Based Deep Learning Framework
**Project Proposal for SIH26066 | Ministry of Earth Sciences**

## 1. Executive Summary
OceanEmbed is a highly efficient deep learning framework designed to reconstruct 3D subsurface ocean temperature profiles using only 2D surface satellite data (Sea Surface Temperature and Sea Surface Height). By eliminating the need for expensive, localized physical sensors, this system provides marine scientists with an accessible, high-resolution, and continuous global subsurface thermal mapping tool.

## 2. Problem Formulation: The Need for Subsurface Data
While surface ocean data is readily available via satellites, understanding the thermal structure of the deep ocean is critical for several global imperatives:

* **Climate Change Monitoring:** Deep ocean layers act as massive thermal sinks. Monitoring these depths is essential to calculate the true rate of planetary warming.
* **Understanding Ocean Circulation:** Deep currents are driven by water density, heavily reliant on temperature and salinity. Tracking these variations reveals how heat and vital nutrients distribute globally.
* **Improving Weather and Climate Forecasts:** Subsurface thermal data is a leading indicator for major climate cycles like El Niño and La Niña, which directly dictate global weather extremes (droughts, floods, storms).
* **Protecting Marine Ecosystems:** Shifting deep-sea temperatures drastically alter deep-water habitats and species distribution. Establishing baselines is vital for fisheries management and the protection of vulnerable marine life.

## 3. The Bottleneck: Difficulties of Physical Measurement
Currently, capturing deep-water temperatures relies on ARGO floats and submersible sensors, which face severe logistical and physical barriers:

1. **Extreme Pressure:** Deep ocean water exerts crushing force. Equipment requires costly, heavy titanium or thick glass casings to prevent sensor implosion.
2. **Remoteness and Access:** Radio waves do not travel through deep water, making real-time telemetry nearly impossible. Deploying ships and submersibles to these locations incurs massive operational costs.
3. **Power and Maintenance:** Devices must survive for months or years on limited battery capacity. Once deployed miles underwater, hardware repairs are virtually impossible.
4. **Dynamic & Hostile Environment:** Deep water changes slowly, requiring sensors to maintain high precision over years. Additionally, biofouling (algae and bacteria growth) can easily obscure sensor readings.

## 4. Proposed Solution & Architecture
To bypass the limitations of physical hardware, OceanEmbed utilizes a **Spatially-Aware Transformer Pipeline (CNN + ViT Hybrid)** to predict depth profiles mathematically.

### 4.1 Why a CNN + ViT Hybrid?
Ocean temperatures are driven by localized mesoscale phenomena (like ocean eddies) and basin-wide macroscale phenomena (like planetary waves).
* **CNNs for Local Features:** The Convolutional Neural Network acts as the feature extractor backbone. Early layers rapidly identify local edges, thermal fronts, and localized upwelling in the satellite imagery.
* **Vision Transformers (ViT) for Global Context:** The Transformer processes the feature maps generated by the CNN. Using self-attention, it maps long-range teleconnections across the entire input grid, understanding how distant ocean sectors influence each other.
* **The Synergy:** By using the CNN to downsample the spatial data into concentrated feature embeddings, the ViT can process the relationships highly efficiently without overwhelming computational resources.

## 5. Technology Stack
The tech stack is optimized for rapid development, precise statistical processing, and scalable cloud performance.

* **Data Ingestion (Python):** Automated pipelines utilizing Copernicus Marine APIs to fetch, temporally slice, and geographically subset multi-dimensional NetCDF satellite datasets.
* **Data Filtering & Preprocessing (Python & R):** Raw satellite data requires rigorous normalization. Python (xarray) handles multidimensional slicing, while robust statistical routines written in R are utilized for probabilistic filtering, anomaly detection, and handling missing data distributions.
* **AI Engine (PyTorch):** The hybrid CNN+ViT architecture, optimized for mixed-precision training to allow deep learning inference on standardized hardware.
* **Database Orchestration (Cloud PostgreSQL):** A highly structured, cloud-hosted PostgreSQL database (with PostGIS extensions) designed to efficiently store generated coordinate embeddings, historical validations, and efficiently route data to the application layer.
* **Frontend & UI (React):** A high-performance, component-based user interface optimized for rendering complex geospatial visualizations without latency.

## 6. User Interface & Wireframes
The application is designed specifically around the workflow of a marine scientist or oceanographer.

* **Main Screen (Geospatial Dashboard):** A large, interactive Leaflet or Mapbox ocean map. The interface includes toggle overlays, allowing scientists to switch between live Sea Surface Temperature (SST) and Sea Surface Height (SSH) thermal maps.
* **Interactive Probing:** When a user clicks on any specific global coordinate on the map, a smooth side panel slides out, initiating an API call to the inference engine.
* **Data Visualization Panel:** The side panel renders a clean, interactive line graph plotting **Depth (meters) on the Y-axis** against **Temperature (°C) on the X-axis**, seamlessly generated by the AI model.
* **Scientific Export:** A dedicated "Export Data as CSV" function allows researchers to instantly download the predicted coordinate depth profile for external modeling and research.
